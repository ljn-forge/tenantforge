# TenantForge Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Deliver the user-approved complete extensible multi-tenant administration product, with real installation, authorization and recovery verification.

**Architecture:** Go modular monolith, same-origin Vue UI, PostgreSQL tenant-owned state and durable jobs, established identity/authorization libraries. Canonical payloads and ownership are defined in docs/api-contract.md.

**Tech Stack:** Go, PostgreSQL/pgx, Casbin, coreos/go-oidc, pquerna/otp, Vue 3, TypeScript, Element Plus, Vite, Vitest, Playwright, Docker Compose.

## Task 1: Backend platform (owned backend files)

Files: go.mod/go.sum, cmd/tenantforge/*, internal/{config,identity,authz,store,platform,modules,httpapi,jobs,storage}/*, migrations/*, backend tests.
- [ ] Write failing pure authorization tests for cross-tenant requests, matching-action union, each scope, row-specific fields and delegation.
- [ ] Implement grant evaluation, validated condition predicates, module descriptors and field projection. Validate using `go test ./internal/authz/...` before integration.
- [ ] Write real PostgreSQL HTTP integration tests: initialization/login/CSRF, tenancy, roles/departments, resources and version conflicts. Run with isolated TF_TEST_DATABASE_URL; confirm failures before implementations.
- [ ] Implement migrations including RLS/runtime permissions, typed endpoints and transactions matching the API contract.
- [ ] Add failing authentication tests for MFA enrollment/recovery/revocation, OIDC state/nonce, password reset token reuse and login limits; implement using maintained protocol libraries.
- [ ] Add all file, job, import/export, audit, notification/settings and quota endpoints with transactional guards, real worker leases and actor revalidation; test denial through each alternate access route.
- [ ] Run `go test -race -timeout 120s ./...`, `go vet ./...`, build; report exact results and any gaps. No silently omitted feature.
